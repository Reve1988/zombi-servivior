# 아트 디렉션 기준 · 비주얼 진단 · 디자인 이슈 현황 (`art-direction.md`)

이 문서는 **OUTPOST ZERO**의 비주얼 기준(아트 디렉션)과 `v0.1.0` 비주얼 진단 결과, 디자인 이슈 현황을 기록해서 에이전트 간 연속성을 유지합니다. 신규 오브젝트, 이펙트, UI는 이 기준을 따릅니다.

---

## 1. 아트 방향

- **스타일:** 이미지 파일 없이 코드로 그리는 **복셀 아이소메트릭 미니어처 디오라마** (떠 있는 섬 받침판, 2:1 아이소, `drawVoxelBox` 기반)
- **키워드:** `장난감 같은 미니어처` · `낮은 채도의 배경 + 선명한 강조색` · `따뜻한 기지 vs 차가운 바깥`
- **참고 감성:** *Townscaper*, *Islanders*(부드러운 미니어처), *Bad North*(밤과 위협의 대비), *Into the Breach*(정보 가독성)
- **핵심 문장:** "정성껏 꾸민 아늑한 기지가 어두운 바깥의 위협 속에서 빛난다."

## 2. 시맨틱 컬러 팔레트 (단일 기준)

색 하나는 의미 하나에만 씁니다. 아래 표에 없는 용도로 강조색을 쓰려면 이 문서를 먼저 갱신합니다.

| 의미 | 색 | 쓰는 곳 | 쓰지 않는 곳 |
|---|---|---|---|
| 전력·에너지 | 청록 `#5EF2FF` | 전력 게이지, 전기 건물 발광, EMP | 사거리 원, 선택 표시, 치명타 |
| 코인·안락함 | 골드 `#FFC94A` | 코인, 안락함, 오라 원 | 일반 경고 |
| 적·위험 | 레드/마젠타 `#FF4D6D` | 적 강조, 경고, 본부 피해 | 아군 건물 |
| 체력·회복 | 그린 `#4ADE80` | HP 바, 수리 | 배경 잔디와 같은 톤 금지 |
| 사거리·선택 | 흰색 반투명 | 사거리 원, 선택 테두리, 호버 | — |

- **배경(지형):** 낮은 채도, 중간 명도. 적과 명도가 겹치지 않아야 합니다.
- **적:** 배경의 보색 계열(자주·적갈색) + 발광 포인트(눈).
- **조명:** 기지 조명은 따뜻한 주황·노랑, 밤 바깥은 차가운 남색 `rgba(7,13,25,…)` 계열.
- 팔레트 값은 CSS 변수와 JS 상수로 한 곳에서 관리하도록 요청되어 있습니다([#3](https://github.com/Reve1988/zombi-servivior/issues/3)).

## 3. 형태와 음영 규칙

### 3.1 광원과 면 음영
- 광원은 **왼쪽 위 고정**입니다.
- 기본색 하나에서 면 색을 정합니다: **윗면 100% / 왼쪽 82% / 오른쪽 66% 명도**.
- 네온이나 발광체(아케이드, EMP 오브, 화면)는 예외로 하되, "발광" 처리로 따로 구분합니다.

### 3.2 카테고리별 형태 언어 (실루엣 규칙)
| 카테고리 | 형태 |
|---|---|
| 방벽 | 낮고 넓게, 모서리를 깎은 사다리꼴 |
| 요원 초소 | 모래주머니 링 + 사람 |
| 자동 포탑 | 원형 받침 + 회전 포신 |
| 전력 시설 | 높고 가늘게 |
| 숙소 | 지붕 모양(박공, 돔) |
| 장식 | 둥글고 유기적 |

- **실루엣 테스트:** 검은색으로 채워도 종류를 알아볼 수 있어야 합니다.

### 3.3 캐릭터
- **2~2.5등신 장난감 비율**(큰 머리). 기본 줌(0.78)에서 높이 16px 이상이 목표입니다.
- 좀비 종류는 색보다 **포즈와 실루엣**으로 구분합니다.
  - 보행자: 팔을 앞으로 내민 자세
  - 러너: 몸을 앞으로 숙인 자세
  - 저거너트: 넓은 어깨 + 방탄판
  - 보스: 뿔, 발광 균열, 바닥 그림자 링

## 4. 조명과 레이어 규칙

- **그리는 순서:** 지형 → 바닥재 → 범위 원 → 구조물·유닛(깊이 정렬) → 투사체·파티클 → **밤 어둠 레이어** → **정보 레이어**
- **정보 레이어**(HP 바, `⚡OFF` 경고, 데미지 숫자, 선택 표시)는 항상 어둠 레이어 **위**에 그립니다. 밤에도 낮과 같은 밝기여야 합니다([#2](https://github.com/Reve1988/zombi-servivior/issues/2)).
- 밤 연출의 핵심은 **온도 대비**(기지 = 따뜻함, 바깥 = 차가움)입니다. 블랙아웃은 약 0.5초 깜빡인 뒤 꺼집니다.

## 5. 이펙트(타격감) 기준

| 우선순위 | 이펙트 | 기준 |
|---|---|---|
| 1 | 피격 번쩍임 | 1~2프레임 흰색 |
| 2 | 총구 화염 | 발사 순간 짧은 빛 |
| 3 | 사망 연출 | 약 0.3초간 쓰러지며 사라짐 + 바닥 자국 |
| 4 | 건설 연출 | 떨어지며 찌그러졌다 펴짐 + 먼지 |
| 5 | 파괴 연출 | 파편 큐브가 흩어짐 |
| 6 | 화면 흔들림 | 폭격, 보스, 본부 피격 때만. 옵션으로 끌 수 있어야 함 |

## 6. UI 기준

- **폰트:** Pretendard를 프로젝트에 포함합니다(현재 CSS에만 지정되어 있고 로드되지 않음).
- **텍스트 크기:** 한글은 최소 12px. 보조 텍스트도 배경 대비를 충분히 확보합니다.
- **아이콘:** 이모지 대신 일관된 SVG 세트를 씁니다. 건설 카드 썸네일은 실제 게임 속 오브젝트 모습으로 표시합니다.
- **화면 점유:** 밤에는 하단 도크를 자동으로 접고, 상단 HUD는 웨이브·본부 HP·전력을 중심으로 보여줍니다. 1600×900 기준 밤에 맵 노출 70% 이상이 목표입니다.
- **월드 텍스트:** 월드 위에는 숫자와 아이콘만 띄웁니다. 문장형 안내는 툴팁이나 토스트로 표시합니다.
- **톤:** UI도 월드의 장난감 톤에 맞춥니다(둥근 모서리, 두꺼운 테두리, 살짝 입체).
